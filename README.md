# LOGIC LAB

## 安装与本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的地址。类型检查和构建：

```sh
npm run typecheck
npm run build
```

## Docker 启动

```sh
docker compose up --build
```

浏览器打开 http://localhost:8028 。

## 反馈研究模式

工作台工具栏可在「组合模式 / 反馈研究」之间切换。组合模式按原规则拦截
反馈连线；研究模式允许搭交叉耦合门，并枚举反馈环的全部联合稳定状态，
区分唯一稳定、多种稳定、无稳定解与受输入控制后才稳定。画布展示所选
稳定状态与各门满足情况，无解时标红形成矛盾的线路。点击元件左下角
⌖ 可钉住内部信号筛选状态；模式与钉住条件随实验一起保存。
